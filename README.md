# MAX · Мессенджер

Минимальный React-клиент для личной текстовой переписки в MAX через GREEN-API. Реализованы вход, создание чата по номеру, отправка сообщений и получение ответов через HTTP API.

## Локальный запуск

Нужен Node.js 22.18+

```sh
npm ci
npm run dev
```

Откройте адрес, который напечатает Vite, обычно http://localhost:5173.

```sh
npm run lint:fix # форматирование и автоматические исправления
npm run check    # ESLint, типы и боевой билд
npm run preview
```

`npm run preview` запускается после сборки.

## Подключение GREEN-API

1. Создайте инстанс **MAX**, авторизуйте его в кабинете GREEN-API и дождитесь состояния `authorized`.
2. В настройках инстанса включите `incomingWebhook` (`yes`) и очистите `webhookUrl`. После изменения подождите около минуты.
3. На экране входа введите `idInstance` и `apiTokenInstance` из кабинета.
4. Нажмите «Новый чат», введите номер получателя с кодом +7 или +375.
5. Отправьте текст. Enter отправляет сообщение, Shift+Enter добавляет новую строку. Максимум 4000 символов.
6. Ответьте из MAX второго аккаунта. Ответ появится в правильной переписке без перезагрузки.

Адрес `apiUrl` берётся из переменной окружения `VITE_API_URL`. Если она отсутствует или пуста, используется `https://3100.api.green-api.com`. Для изменения адреса скопируйте `.env.example` в `.env` и задайте `VITE_API_URL`. После изменения перезапустите `npm run dev`.
